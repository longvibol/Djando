When we want to redirect the condition, we can use the if condition template when it fail back:

Ex: 

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title> {{ month_name }} Monthly Challenges</title>
</head>
<body>
    <h1>{{ month_name | title }} Challenges</h1>
    {% if text is not None %}
        <h2>{{text | title}}</h2>
    {% else %}
        <p>There is no challenge for this month yet!</p>
    {% endif %}
</body>
</html>
